# React 

This repository is a collection of React mini-projects and learning exercises inspired by YouTube-style tutorials. Each folder is an independent Vite React app covering a different topic or concept.

## Project structure

- `01-folder` — basic React/Vite setup and folder structure
- `02-components` — React components fundamentals
- `3-props` — props usage and passing data between components
- `04-cards-project` — card UI project using React and styling
- `13-notes-app` — notes application example
- `15-API-Use-effect` — fetching data with `useEffect`
- `16-UseEffect` — React effects and lifecycle patterns
- `18-react-router-dom` — routing with React Router
- `19-routing-advanced` — advanced routing concepts
- `21-context-api` — state management with Context API

## Tech stack

- React
- Vite
- JavaScript
- CSS
- HTML

## Getting started

Each folder is a standalone React project. To run any project:

```bash
cd <project-folder>
npm install
npm run dev
```

Example:

```bash
cd 04-cards-project
npm install
npm run dev
```

## Notes

This repo is primarily for learning and experimentation with React concepts, component design, routing, context, API usage, and UI patterns.
